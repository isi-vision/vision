# vISIon: The ISI Magazine

The website of *vISIon: The ISI Magazine*, published twice a year by the [International Statistical Institute](https://isi-web.org).

**Read the magazine:** https://isi-vision.github.io/vision/

Each issue centres on one UN Sustainable Development Goal and gathers perspectives from across the ISI's seven associations. Every issue is free to read, with no subscription and no paywall.
